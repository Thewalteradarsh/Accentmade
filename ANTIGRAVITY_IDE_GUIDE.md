# Accent Made (accentmade.com) — Google Antigravity IDE Workspace

## 1. Quick Start in Google Antigravity IDE
1. Unzip `accentmade_antigravity_project.zip` and open the folder in **Google Antigravity IDE** (`File -> Open Folder...`).
2. Run a local live preview server (or ask the Antigravity Agent: *"Start a local HTTP preview server on port 8080"*):
   ```bash
   python3 -m http.server 8080
   ```
3. Open `http://localhost:8080` in the Antigravity browser preview pane.
